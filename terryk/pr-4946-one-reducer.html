Status
Refactor — same numbers before and after. Merged on 2026-11-20. It adds two startup checks that stop runs which used to go wrong quietly (table at the bottom).

Background. The policy loss starts as one number per response token. It must be averaged to one number. There are two ways: global_token_mean adds every token in the batch and divides by the token count, so long answers weigh more. sequence_mean averages inside each response first, then averages the responses, so each one weighs the same.

The single-controller Megatron trainer trains one step in pieces (train_microbatch chunks). It cannot know the batch's total count until the last chunk, so each chunk divides by 1 and the real count is applied once at the end. Page 2 walks through that path. Dotted words have a short explanation: hover or tap them.

The PR adds ObjectiveReduction with two subclasses, GlobalTokenMeanReduction and SequenceMeanReduction. Each one has three methods: reduce() turns per-token values into one number, local_counts() counts tokens and responses in one chunk, and loss_divisor() picks which count to divide by. The loss makes its reducer once, in __init__, and every term goes through it.

One average, computed in two chunks

What moved: five copies of one if become one object

The loss, before

# ClippedPGLossFn.__call__: policy worker, once per microbatch
if token_level_loss:                                                     # copy 1: actor loss
    actor = sum(v · mask) / global_valid_toks                            # token mean
else:
    actor = sum(mean_per_response(v) · sample_mask) / global_valid_seqs  # sequence mean
if TOKEN_LEVEL: kl = … else: kl = …                                      # copy 2: KL penalty
if TOKEN_LEVEL: actor += … else: actor += …                              # copy 3: score centering
if TOKEN_LEVEL: opd = … else: opd = …                                    # copy 4: OPD-full
log loss, kl ÷ TOKENS or SEQUENCES                                       # picked from loss_type

The loss, after

# ClippedPGLossFn: __init__ once, __call__ per microbatch
R = make_objective_reduction(cfg.resolved_normalization)  # GlobalTokenMean… or SequenceMean…
d = R.loss_divisor(global_valid_toks, global_valid_seqs)  # toks or seqs
actor = R.reduce(v, masks, d)                             # was copy 1
kl    = R.reduce(kl, kl_masks, d)                         # was copy 2
actor += R.reduce(adv · centering, masks, d)              # was copy 3
opd   = R.reduce(divergence, masks, d)                    # was copy 4
log loss, kl ÷ LOSS_DIVISOR                               # whatever divided the gradient

Real code: clipped_pg_actor_objective, ClippedPGLossFn.__call__, _opd_full_call.reduce_like_loss. mean_per_response(v) is the inner masked_mean(v, token_mask, dim=-1).

The streaming worker's half of the change (counting each chunk and dividing once at the end) is on page 2.
