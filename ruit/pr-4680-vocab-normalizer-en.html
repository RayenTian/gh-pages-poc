The first three pages explain the new feature and two reproduced issues; page 4 is a split proposal and page 5 is the PR author's own split plan. Review comments have not been staged or published.

Background: Megatron's output layer can be wider than the number of tokenizer IDs. Context parallelism (CP) splits a sequence across processes; owner-local makes the process that holds a comparison chunk compute that chunk, to save GPU memory. It should keep the loss of the replicated reference path.

The two owner-local student calls pass the tokenizer length to a helper that masks the tail columns, while the replicated student normalization uses the full model output. The issue affects both CE and KD; it does not only change logging.

Same logits, two answers

z is the student logit; j is the target token; Vmodel is the number of model output columns and Vtokenizer is the number of tokenizer IDs. The two denominators today:

\log p_j^{\mathrm{rep}}=z_j-\log\sum_{v=0}^{V_{\mathrm{model}}-1}e^{z_v}
\log p_j^{\mathrm{owner}}=z_j-\log\sum_{v=0}^{V_{\mathrm{tokenizer}}-1}e^{z_v}

To separate CE from KD, the reproduction turns dynamic_loss_scaling off explicitly and uses fixed weights; these numbers are not real model training results under the default config.

The public model config of the real Qwen3-4B has 151936 columns; the tokenizer at the same revision has 151669 distinct IDs, a difference of 267 columns. This shape condition exists in practice; that model was not run.

Suggested fix: keep the reference objective — not merged

Change the student normalization range in two places in RL. Make both CE and KD use the global model output width, that is, local columns × TP size. Teacher inputs are already cut to the real vocabulary on both paths, so no change is needed to the teacher, Bridge or Megatron-Core.

These two equivalent changes were verified in memory on the real CSD module: with and without student tail columns, with dense/sparse teachers and with mixed teachers, values and gradients match again. A TP/CP parity regression test with a padded student is recommended.
